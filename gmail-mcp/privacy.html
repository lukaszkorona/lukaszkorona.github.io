gmail-mcp — privacy policy

Last updated: 8 October 2026

gmail-mcp is a personal tool used only by its author to access the author's own Google accounts. It is not offered to the public.

Data accessed

With the user's consent, the tool uses the Gmail API (scopes gmail.readonly, gmail.compose, gmail.modify) to read messages and settings, create and edit drafts, and change labels of messages in the signed-in account.

How data is used and stored

  • Data is processed only on the author's own computer, on the author's request.
  • OAuth tokens are stored locally on that computer with owner-only file permissions.
  • No Google user data is sold, shared with third parties, used for advertising, or used to train generalized AI or machine learning models.
  • The tool never sends email on its own; drafts are reviewed and sent manually.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; local tokens are then deleted.
